在轨编程上注使用说明

适用版本：V1.0.5（及后续保持相同页面和组帧规则的版本）

本页用于选择一个二进制文件，按指定行长拆分后批量生成高速遥控帧。生成结果只供检查和导出，不会自动发送到设备。

固存测试建议

测试固存时，将 PID 设置为 0x0A。其余参数建议先使用页面默认值：

  • SCID：0xFF01
  • VCF：0
  • PCAT：0x03
  • VCID：10
  • MAP ID：14
  • 分段标志：11 · 独立包
  • 包序列计数：0（只读）
  • 添加422格式：不勾选
  • 每行读取字节长度：勾选，962 字节

PID 与 PCAT 一起构成 APID：APID = (PID << 4) | PCAT。例如 PID=0x0A、PCAT=0x03 时，APID 为 0x0A3。导出文件名会以 APID_0x0A3_ 起始。

PID 是 7 位字段，页面支持十进制和 0x 十六进制输入。输入 0x0A 即 PID 十进制 10。请根据测试对象要求核对 PCAT；本说明中的默认 PCAT 是 0x03。

建议操作步骤

  1. 打开 在轨编程上注 页面，选择目标文件。
  2. 固存测试时把 PID 改为 0x0A；确认 PCAT=0x03，其余按“固存测试建议”使用默认值。
  3. 保持“添加422帧格式”未勾选；保持“每行读取字节长度”勾选，填 962。
  4. 点击“生成帧”，等待状态从“正在批量生成”变为帧数和每帧长度摘要。
  5. 用帧选择框检查首帧、中间帧和尾帧，确认 APID、VCF、分段标志及尾部 AA 填充符合测试要求。
  6. 按交付接口选择下载：交付瑞信丰时，点击“下载上注用指令（.dat）”，生成单个连续高速帧文件；需要表格检查时用 .xlsx。仅需应用数据时使用“逐帧下载数据区”。

下载文件只包含生成结果，不包含上传的原始文件副本或页面日志。工具输出为未加扰、未做信道编码且不含 CLTU 的原始帧。

页面参数

参数页面默认值说明与可选范围
上注文件未选择选择要组帧的原始二进制文件。此模式不提供应用数据 HEX 输入。服务端单文件上限为 64 MiB。
SCID0xFF0116 位航天器标识，随页面请求传入；除非地面/星上接口另有要求，建议保留默认值。
VCF 帧计数08 位帧计数值，范围 0..255。在轨编程的所有生成帧都使用同一个 VCF，不会逐帧递增。
PID2PUS APID 的 PID 部分，范围 0..127。固存测试按要求改为 0x0A。
PCAT0x03APID 的 PCAT 部分，范围 0..15。默认即可，除非测试规程指定其他值。
VCID10高速虚拟信道，可选 10、5、4、63。建议默认 10。
MAP ID14MAP 标识，可选 14（大容量数据）或 1（指令/注入）。建议默认 14。
分段标志11 · 独立包默认 11 时每一帧都作为独立包，包序列计数固定为 0。选择其他标志时，多帧按首段、延续段、尾段设置 01、00、10，包序列计数按帧递增；单帧仍按独立包生成。
包序列计数0（只读）页面显示基础计数，但当前不可编辑。选择 11 时所有帧均为 0；选择其他分段标志时，多帧包的计数依次递增。
添加422帧格式（0XEB90）不勾选勾选后，每帧应用数据在 5F01 后加 EB 90 0F、2字节有效数据长度、该帧文件数据和1字节累加和。累加和覆盖 0F + 长度 + 文件数据，不包含 EB 90。勾选后每行文件数据最多 956 字节；不勾选时保留 5F01，每行最多 962 字节。建议按固存测试默认关闭。
每行读取字节长度勾选，962勾选时按输入字节数拆分，422关闭时范围为 1..962，422开启时范围为 1..956；关闭时自动采用最大行长：422关闭时 962 字节，422开启时 956 字节。建议保留默认的勾选和 962。

页面通用的“刷新当前页”按钮会清除当前页文件、参数和生成结果，并把在轨编程设置恢复为上述默认值。切换到其他功能后再切回在轨编程，页面会保留上一次输入和设置。

组帧和填充规则

  • 每个输出高速帧固定 1020 字节；帧内 TFDZ 为 977 字节。
  • PUS 主导头、副导头和包 ECF 共占 13 字节，留给应用数据最多 964 字节。
  • 不勾选输入侧422时，应用数据为 5F 01 + 文件数据，因此每帧最多读取 962 字节文件内容。
  • 勾选输入侧422时，应用数据为 5F 01 + EB 90 0F + 长度(2字节) + 文件数据 + 累加和(1字节)，每帧最多读取 956 字节文件内容。
  • 勾选固定行长后，最后一段不足所填行长时先用 AA 补到行长；帧内剩余空间再按帧格式补 AA。未勾选固定行长时，最后一段按实际长度写入，剩余帧空间仍由帧生成器补 AA。
  • 若文件长度正好整除行长，不会额外生成空帧。空文件会生成一帧仅含 5F01 的有效应用数据帧。
  • 当前批量生成接口单文件限制为 64 MiB、最多 100,000 帧。输出帧按文件读取顺序排列。

生成结果区和按钮

多帧结果使用“选择帧”下拉框浏览。下拉框只改变当前预览和复制操作所针对的帧；批量下载按钮仍按完整帧序列导出。

按钮导出内容文件数量及命名
复制整帧 HEX复制当前选中帧的完整 1020 字节十六进制文本，包含帧头、PUS、数据区、填充和帧校验字段。不生成文件。
复制数据区 HEX复制当前帧 PUS 包中的应用数据，不含 PUS 主/副导头和包 ECF。输入侧422关闭时内容以 5F01 开始；开启时还包含 EB900F 封装。不生成文件。
逐帧下载（.bin）每帧完整的 1020 字节二进制高速帧。每帧一个 BIN；多帧文件名按 _1、_2…编号。下载前会确认文件数量。
逐帧下载数据区（.bin）每帧的应用数据字节，不含帧头、安全区、PUS 主/副导头和包 ECF；包含应用层 5F01，若启用了输入侧422也包含该422封装。每帧一个 BIN；文件名带 _data 和分包序号。下载前会确认文件数量。
下载上注用指令（.xlsx）一个 Excel 文件，含“整帧数据”“TFDF有效数据”“422数据”三个工作表，每帧一行。第三张表按 EB 90 0E + 长度 + 3字节TFDF导头 + TFDF数据 + 累加和 生成。尾帧会包含完整 TFDZ 和 AA 填充。一个 XLSX。此导出422格式独立于上方“添加422帧格式”勾选项。
下载 422 BIN将每帧对应的 EB 90 0E 格式数据按帧顺序连续写入同一个 BIN。内容含3字节 TFDF 导头；尾帧含完整 TFDZ 和填充。一个 BIN。此导出也独立于输入侧422勾选项。
下载上注用指令（.dat）把所有完整 1020 字节高速帧按帧序合并为一个 DAT 文件。一个 DAT，供瑞信丰使用的单个连续高速帧文件。

以上导出按钮点击后会弹出确认框，显示将下载的文件数量；确认后浏览器开始下载。若浏览器阻止多个自动下载，请允许此站点下载多个文件。文件名前缀由当前 PID 和 PCAT 计算，例如固存测试 PID=0x0A、PCAT=0x03 时以 APID_0x0A3_ 开始。页面参数不合法时，文件名前缀可能显示为 APID_UNKNOWN_。
